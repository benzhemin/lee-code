# LeetCode Java solutions

Java solutions are under `src/main/java/`, grouped by problem number. Shared helpers are in `src/main/java/common/`.

Run the Gradle build with `./gradlew test`.

Run the default example with `./gradlew run`, or select another solution with `./gradlew run -PmainClass=p20.ValidParentheses`.

JavaScript solutions are in the separate `lee-code-js` repository.

For VS Code, open `../lee-code.code-workspace` so the Java repository is imported as its own Gradle project.
